# EME Experiment Data Management System · EME 实验数据管理系统

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

电膜萃取（EME）实验 LC-MS 数据的一站式本地管理工具：**自动解析仪器导出 → 计算回收率/转移率/RSD →
生成带真实公式的 Excel 留痕 → 跨实验质控看板**。Streamlit + SQLite + openpyxl，数据全本地，无需联网。

> **适用范围**：本工具为 **AB SciEX 液质联用仪的长表格导出**设计——即每行一条
> "样本 × 组分（离子对）" 记录的制表符分隔 txt（列含 Sample Name / Component Name / Area /
> Retention Time，即本系统的 ALLDATA 格式；配套的 AREA+RT 宽表对也已兼容）。
> **其他品牌（Thermo / Waters / Agilent 等）或其他导出格式未经测试**——它们通常只需在
> `eme_db/parser.py` 的列名映射（`_ALLDATA_COLS`）里补充别名即可适配，欢迎提 issue 反馈。

**⬇️ 免安装便携版**（Windows）：见右侧 [Releases](../../releases) —— 下载解压，双击 `EME_Data.exe` 即用。

## 一、安装与启动

### 便携版（推荐给新用户）

1. 解压收到的 `EME_Data` 文件夹到任意位置（路径建议不含中文以外的特殊字符）。
2. 双击 `EME_Data.exe`，约 2 秒后浏览器自动打开系统页面。
3. 关闭黑色命令行窗口即停止服务。

- **杀毒软件拦截**：若提示 `python311.dll` 风险，属误报，将整个文件夹加入白名单即可。
- **完整性自检**：在文件夹地址栏输入 `cmd` 回车，执行 `EME_Data.exe selftest`，
  看到 `SELFTEST OK` 即文件完整可用。
- 端口占用时自动顺延（8501 起）；多开实例各用各的端口，数据各自独立。

### 源码版（需要改代码或看实现时）

依赖：Python 3.11，及 `requirements.txt` 所列包（streamlit、pandas、numpy、openpyxl、
plotly、matplotlib、simpleeval、Pillow）。

```bash
pip install -r requirements.txt
# Windows：双击 eme_db/run.bat（重复双击 = 自动重启服务并加载最新代码）
# 或命令行：
streamlit run eme_db/app.py
```

源码版与便携版的数据目录相互独立，不要混用。

## 三、首次使用准备

### 1. 分析物信息库 `analyte.xlsx`

- 工作表 `drug`（或任何含"名称/name"列的表）：一行一种分析物。
- 必有：物质名主键列（列名含 `名`/`name` 即可，如 `Input-englishname`、`物质名`）。
- 常用可选列（列名自适应，新旧表头都认）：`C-LogP`/`LogP`、`C-HBA`/`HBA`、`C-HBD`/`HBD`、
  `C-TPSA`/`TPSA`、`C-pka-A`、`C-pka-B`、`C-精确分子量`、`CAS`、缩写列（`缩写`/`Abbreviation`）。
- **pH 宽表**（可选，如 `LogD`、`charge`、`solubility`）：第 1 列物质名、第 2 列属性名、
  第 3 列起为 pH 0.0~14.0 的数值列。程序自动识别所有此类工作表。
- 物质名的**缩写/全称/商品名**任一形式都能互相匹配（名形映射自动建立）。

### 2. SLM 试剂信息库 `SLM.xlsx`

- 四类工作表：`LF-液膜类`、`DES-深共晶类`（主 SLM）；`IL-离子液体类`、`O-其他`（添加剂）。
- 主键列 = 试剂名称列（含 `名`/`name`）；若有 `英文名` 列则图片优先按它匹配。

### 3. 结构式图片

- 放入 `data\photo\Analytes\`、`data\photo\SLM\`，文件名 = 物质名（`.png`/`.jpg`）。
- 支持 `物质名-structures.png` 等变体；大小写不敏感；SLM 优先按英文名匹配。
- 可在「🗂️ 信息库」页指定自定义图片文件夹。

### 4. 仪器导出要求（AB SciEX 长格式）

- 本系统按 **AB SciEX（Analyst/SciexOS）的长表格 txt 导出**设计：每行一条"样本×组分"记录。
- **首选** `日期-ALLDATA.txt`：需含 样本名（Sample Name）、组分名（Component Name）列、
  峰面积（Area）、保留时间（RT）；建议同时勾选导出 **SN（Signal/Noise）**、峰高（Height）、
  半峰宽（Width at 50%）——三者缺省只是少对应的表，不影响主流程。
- 也兼容 AB 的 `日期-AREA.txt` + `日期-RT.txt` 宽表组合（此时无 SN/峰高表）。
- **其他品牌/格式未测试**：Thermo/Waters/Agilent 等的导出如需接入，一般改
  `eme_db/parser.py` 里的列名映射即可，不一定动主逻辑。
- N/A 与空值按 0 参与计算；同一样本重复进样取第一次并警告。
- 样本命名格式默认 `1-A-1`（组-相-重复），支持 `A1-1` 预设与自定义正则（见 十三）；供体相用 `D` 或 `S` 均可（`1-D-1` 自动按供体相识别，内部统一记作 S）。

## 四、新增实验（6 步流程）

导航选「➕ 新增实验」：

**① 选择实验文件夹**：下拉选择 `data\experiments\` 下的文件夹；
   或展开「📤 直接拖入数据文件」，把 txt 拖进去自动建文件夹（默认名 `日期-组数F`）。
   已录入过的文件夹会自动回填上次的所有录入信息（重新生成会覆盖）。
   可在此删除传错的文件夹。

**② 核对质控样/空白样名称**：下拉列出文件中**全部**样品名（⭐/☆ 只是自动识别标记，
   任何进样都可指定为标准品/空白）。四个角色：受体标准品/供体标准品/受体空白/供体空白。
   多标准品组合：勾选「实验组使用不同的供受体相质控样」→「➕ 添加一组标准品组合」，
   为每个组合命名并指定四个角色，之后可给每个实验组指派不同组合。
   改完可点「🔄 应用质控名重新解析」。

**③ 实验元数据**：日期/温度/湿度/液相平衡柱压/Va/Vd/实验说明；
   勾选「使用样品（启用供体相）」才会计算转移率。可选关联电流记录 sheet（可多选）。

**④ 萃取条件**：先填**基准条件**（主SLM 支持多选混合膜+比例；三处添加剂可选 SLM 表全部
   物质并逐个填含量/浓度，单位自定）。然后两种模式任选：
   - **📋 表格快速设置**（推荐）：一张表编辑所有组，留空=继承基准，改动=覆盖该组；
     SLM 膜中添加剂/孔位/异常标签在表格下方的展开区逐组点选。
     *表格编辑实时备份，页面刷新不会丢失；改错的组名单元格会被忽略。*
   - **🔧 逐组详细设置**：每组独立展开，勾「覆盖」才修改该字段。
   - 两种模式切换时自动互相同步。
   - 组别名默认按实验目的自动生成（如 `SLM-NPPE+DEHP-AceA2.4+DEHP-FA3.0`），
     留空即可；手动填写则以此为准。若某组缺 SLM 信息，生成时会弹出明确警告。

**⑤ 生成**：点「✅ 生成 Excel + 写入数据库」→ 生成 `日期-DATA.xlsx` 并入库。

**⑥ 标准品质量检查（可选）**：按标准品名称分节显示每针峰面积矩阵与偏离度推荐；
   在「剔除」列勾选离群针（该列与进样针名一同冻结，左右滚动不消失），
   下方实时统计 RSD>15% 物质数与 RSD% 累加。同一标准品名两相共用时支持联动剔除
   （勾一针，另一相同名同号针同剔）。确认保存后数据库与 Excel 同步重算。

## 五、实验详情页（6 个页签）

顶部下拉选实验；侧栏有物质/试剂详情卡（按该实验供体相 pH 显示 LogD/电荷等随 pH 性质）。

1. **萃取条件**：各组条件总表 + 回收率/供体相至SLM转移率/SLM至受体相转移率三张热图
   （配色可换、色标独立、RSD>15% 红字、每列底部统计行：📊<20 / 20~40 / ≥40 / 有效膜数；
   统计行恒白底）。可设 1~2 条参考线（设置页改默认值）。
2. **⚡ 电流曲线**：按时间-电流作图（x = 序号/120 分钟），显示平均电流参考线。
3. **🧊 三相分布与基质效应**：多选实验组、每组一张受体相/膜/供体相堆积图（含误差棒）；
   标准品一致性检查（50% 参考线，偏离>20 个百分点提示可能基质效应）；
   标准品对比（任选两个标准品名，同名针取平均、可剔针、RSD 红标）。
4. **🔧 剔除异常数据**：在峰面积表中「剔除」列勾选（剔除列与样本名一同冻结）；
   勾选即时重算——表格下方实时显示剔除后 RSD>15% 物质数与 RSD% 累加，
   RSD 明细表红标超阈物质。确认后一次保存同步数据库与 Excel（灰标/修正列保留）。
   已保存的剔除会预勾选，取消勾选即恢复。
5. **✏️ 修改/删除**：改元数据/组条件/标准品剔除后点「💾 保存修改并重新生成 DATA.xlsx」
   一并生效；也带多标准品组合编辑器。删除实验在下方（默认选中当前查看的实验）。
6. **📌 观察记录**：本实验关联的记录（与侧栏观察记录互通，可编辑），含图片。

## 六、实验汇总页

- 顶部实验列表总览（日期/文件夹/目的/组数/温湿度/说明）。
- 三个指标表（回收率 / 供体相至SLM转移率 / SLM至受体相转移率）以
  **日期 → 组别名** 两级表头展示，色阶着色；RSD 显示可开关（关=纯色阶）。
- 「⛶ 展开全部」完整显示所有物质行（浏览器滚动查看，组件内不再滚动）。
- 底部统计行按**每组一列**统计（<线1 / 线1~线2 / ≥线2 或 <20/20~40/≥40）+ 回收率表恒有有效膜数行。
- 筛选：实验日期 / 主SLM / 添加剂 / 分析物；物质名列冻结可读。
- 同一天多次实验自动以「日期（文件夹名）」区分。
- 侧栏物质详情（pH = 该物质所在实验的供体相 pH）。

## 七、质控看板（8 个分区）

1. **跨实验峰面积质控**：标准品平均峰面积 vs 日期散点，固定 ±15% 质控线 + 实际跨实验 RSD；
   多选分析物同图叠放（按物质着色，各自 ±15% 虚线带）。
2. **跨实验保留时间/半峰宽质控**：同上口径；每张 RT 图下方附对应半峰宽 QC 图。
3. **🌡️ 实验环境质控**：温度/湿度/柱压三张独立时序图。
4. **单次实验 RSD 柱状图**：选实验 → 各物质 RSD 柱状（>15% 红线）。
5. **📈 单次实验保留时间散点**；**📈 单次实验半峰宽散点**（全部物质按物质着色）。
6. **单次实验 RSD 表**：日期×物质数字表，>15% 标红。
7. **RT 波动统计**：max−min，波动最大者高亮。
8. **📈 跨实验 RSD 超阈统计**：全库扫描 RSD>15%，按分析物透视
   （超阈次数/涉及实验数，≥3 次标红），并给出判定提示——
   同一物质反复超阈→怀疑仪器响应；多物质同日期超阈→怀疑单次状态（列出最严重日期）。
   另有 **⚠️ 异常统计**：按主SLM 汇总渗漏/烧焦/破裂标签（同一 SLM 反复异常=试剂稳定性），
   96 孔板散点定位（同一列/行反复异常=怀疑电极棒）。

## 八、自定义看板

- 每个面板 = 一个实验组；组内可「➕添加XY」叠加多组坐标。
- X 轴：分析物的任意信息库列（LogP/HBA/TPSA…）+ 随供体相 pH 派生列（`LogD@供体pH` 等）；
  Y 轴：回收率/两种转移率/两种 RSD。
- 「➕添加面板」对比不同组；配置可存为偏好并加载（✏️重命名/🗑删除）。
- 统一 Y 轴范围开关；组→颜色按首次出现顺序分配，必不撞色。
- 多选分析物/试剂 → 侧栏同时显示多张详情卡。

## 十、公式说明与自定义公式

- **📐 内置公式**：回收率（空白双轨）、校正系数、D→M、M→A、RSD、三相分布、RT 波动——逐条给公式。
- **✏️ 自定义公式**：最多 8 个，可用变量 `A_mean / S_mean / STD_acceptor_mean / STD_donor_mean /
  blk_acceptor_mean / blk_donor_mean / Va / Vd / pH_donor / pH_acceptor / corr`；
  计算结果作为附加列出现在热图。求值失败会逐行给出原因（不再静默）。
- **🧪 公式测试器**：代入示例值即时试算。

## 十一、实验前计算器

1. **💧 稀释计算**：C₁V₁=C₂V₂×损失系数。
2. **🧴 标准需求量**：理论/推荐配制体积（向上取整到 100 μL）+ 储备液用量；
   浓度单位可选 μg/L(≈ppb) / mg/L。
3. **🧪 流动相配比**：甲酸/甲醇/水体积（比例合计≠100% 会提醒）。
4. **⚖️ 摩尔浓度试剂配制**：质量（向上取整到 0.001 g）/体积；固体无密度时只算质量；
   试剂表可增改（MW/密度），可恢复内置默认。

## 十二、信息库维护

- 直接编辑 `data\analyte.xlsx` / `SLM.xlsx`（加行加列都行），回到「🗂️ 信息库」点 **🔄 刷新**

## 十三、设置页

- **默认参数**：温湿度/pH/萃取时间电压/体积/添加剂浓度默认值。
- **样品名称格式**：`1-A-1`（组-相-重复）或 `A1-1`（相-组-重复）预设，或自定义正则
  （必须含 g/ph/r 三个命名组；相位位写 `[ASD]` 即可让供体相用 D 命名，程序自动把 D 归一化为 S）；
  全局默认 + 每实验覆盖（录入时单独选）；旧版设置的格式会自动升级支持 D。格式不对导致 0 组时，
  程序会自动按预设自愈并提醒。
- **参考线**：回收率 1~2 条（清零=不启用）；转移率同。
- **自定义试剂标签**：录入时自由输入的新试剂自动登记（🔧 标识），信息库加入同名试剂后自动"转正"。
- **配色偏好**：热图/汇总的 colormap 选择自动记忆。

## 十四、DATA.xlsx 输出文件说明

| 工作表 | 内容 |
|---|---|
| 总表 | 元数据区（温湿度/pH/Va/Vd/质控名/说明）+ 组条件总表 + 标准品峰面积汇总 |
| 数据汇总 | 物质×实验组五大矩阵（回收率/两种转移率/两种RSD），LogP/charge@供体pH 性质列，色阶+统计行（真实 COUNTIF 公式），组别名完整显示（长名自动换行） |
| RT表 / SN表 / 峰高表 / 半峰宽表 | 样本×物质透视（SN/峰高按列存在才生成） |
| 电压表 | 时间-电流（来自 current\ 的关联 sheet；空表可手贴） |
| M1~Mn | 每组：受体/供体各重复峰面积（缺失重复留空、被剔除标灰）+ 均值/RSD/回收率/转移率 **真实公式**（改数即重算）+ 修正列（剔除后重算值）+ 孔位/异常标签/备注 + 底部三张原生图表（三相分布 / RSD-回收率散点 / LogP-回收率散点，全实验统一 0~100 自动扩展轴） |

> 留痕原则：原始值永不删除，剔除只标灰 + 修正列重算；所有统计为真实 Excel 公式可核对。

## 十五、数据备份与软件升级

- **备份**：复制整个 `data\` 文件夹（含 eme.db、experiments、photo、user_settings.json）。
- **升级便携版**：新 `EME_Data` 文件夹解压后，把旧 `data\` 覆盖进去即可；数据库结构自动迁移。
- **升级源码版**：覆盖 `eme_db\` 代码后重新双击 `run.bat`（自动重启加载新代码）。
- **重新生成旧实验**：在「新增实验」选该文件夹 → 生成，会用保存的质控名/剔除记录重算，结果一致。

## 十六、常见问题 FAQ

**Q1 页面打不开 / 端口被占？** 程序自动换端口（8501 起）；命令行窗口里会打印实际地址。
**Q2 杀毒报 python311.dll？** 误报，整文件夹加白名单；`selftest` 验证完整性。
**Q3 改了代码/新版本不生效？** 便携版需重新打包；源码版重新双击 `run.bat`（会自动重启旧服务）。
**Q4 解析出 0 个组？** 样品名格式不符——页面上方会提示；选对「样品名称格式」或自定义正则。
**Q5 找不到我的标准品？** 质控下拉列出文件里全部进样名，任何名字都可指定；自动识别只认
   含 STD/BLK 字样或 bz/kb 开头的名字，其余请手动选。
**Q6 组别名全变 M1、M2？** 该组缺 SLM 信息（基准和分组都没填主SLM）。生成时有黄色警告列出
   具体组号；填好后重新生成即自动补全，或到「修改/删除」手填。
**Q7 剔除错了想恢复？** 剔除页/修改页取消勾选再保存；已保存剔除会预勾选显示。
**Q8 Excel 文件被占用导致保存失败？** 关掉打开的 DATA.xlsx 再点一次保存；数据已在数据库中，
   重试只重写文件。
**Q9 想把软件给同门？** 直接发整个 `EME_Data` 文件夹（或从 GitHub Releases 下载便携版）；
   对方拿到的是空白模板，从「新增实验」拖入自己的 txt 即可开始。
